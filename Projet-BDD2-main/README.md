# Projet-BDD2
Définir le schéma d’une base de données que vous allez développer et améliorer tout au long du cours. Vous allez pouvoir améliorer les performances de vôtre base en introduisant des clés, des indexes, des clusters et des vues matérialisées. Votre base de données doit être normalisée en 3FN et en FNBC.
